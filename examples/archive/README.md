# Archived data from the supplied project

`legacy_analysis_data.csv` is the older algorithm's unverified output. It is preserved for provenance and comparison. Its derived speed, acceleration, gravity, restitution, and energy values have **not** been validated and should not be used as expected answers for this release.

To reanalyze it, inspect the provenance and units of its `Time`, `X`, and `Y` measurements first. The new engine cannot repair an incorrect original calibration or timing convention.
